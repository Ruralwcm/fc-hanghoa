Mở Google Sheet ↗

Dán URL Web app của Apps Script (kết thúc bằng /exec). URL được nhớ trên trình duyệt này và dùng chung cho các app trong Portal.

Cài đặt Apps Script (làm 1 lần)
  1. Mở Google Sheet "FC Portal - Dữ liệu chung" → Tiện ích mở rộng → Apps Script.
  2. Xóa code mẫu, dán toàn bộ file Code.gs → Lưu.
  3. Triển khai → Tùy chọn triển khai mới → Ứng dụng web · Thực thi với tư cách: Tôi · Người có quyền truy cập: Bất kỳ ai → Triển khai, cấp quyền.
  4. Sao chép URL /exec, dán vào ô trên rồi bấm Kiểm tra → Lưu.
